
# Project Name: Bank Account Management System

## Project Description
This project is a Java console-based banking application that allows users to manage customers and bank accounts. Users can create checking, savings, and IRA accounts; view information; deposit and withdraw money; update customer names; and delete bank accounts. The application uses SQLite to save information so it can be accessed again after the program closes.

## Project Tasks
- **Task 1: Set up the development environment**
- Set up Java and development tools
- Configure the SQLite JDBC driver and project files
- Set up the GitHub repository for version control
  
- **Task 2: Plan the project**
- Decide which banking features to include
- Design the Customer, BankAccount, CheckingAccount, SavingsAccount, and IRAAccount classes
- Plan the console menu and how the classes work together

- **Task 3: Implement core features*
- Create the banking menu and account classes
- Add deposit and withdrawal operations through the BankingOperation interface
- Use inheritance and polymorphism for different account types
- Connect the application to SQLite and add create, read, update, and delete operations

- **Task 4: Test the application**
- Check account creation, account searches, deposits, and withdrawals
- Test customer updates and account deletion
- Check input validation and database error handling
  
- **Task 5: Document the project**
- Create a README file describing the application
- Document the classes and their responsibilities

- **Task 6: Finalize and submit**
- Review the code and project file
- Upload the final project to GitHub
  
## Project Skills Learned
- Java object-oriented programming, including inheritance, abstraction, composition, and polymorphism
- Creating and implementing Java interfaces
- Using SQLite and JDBC to store and retrieve data
- Implementing CRUD (create, read, update, delete) operations
- Validating user input and handling exceptions
- Documenting a project and using GitHub for version control
  
## Language Used
- Java: Used to build the console menu, account classes, and banking operations
- SQLite: Used to store customer and bank account records and perform CRUD operations
  
## Development Process Used
- Incremental Development: This application was developed in phases. I started by planning the banking system and creating the account class. I then added inheritance, an interface, and banking transactions. In the later phase, I added SQLite database storage and CRUD operations to save and manage the information.
